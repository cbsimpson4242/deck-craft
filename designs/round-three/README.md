# Signal + Studio / Refinement Round 03

## Confirmed brief

The user liked **Signal** and **Studio** from Round 02 and requested five more mockups refining those directions. This is not a new independent design contest or a palette-only exercise. Preserve the technical cool-dark instrument language, waveform priority and collection workflow while improving hierarchy, proportion, control consistency and readability.

## Exactly five new proposals

| Study | Lineage | Main refinement | Trade-off |
| --- | --- | --- | --- |
| Signal One | Signal | Clearer deck hierarchy, larger time/BPM readouts, two visible cue banks and calibrated side mixer. | Conventional two-deck layout; most faithful to Signal. |
| Signal Wide | Signal | Give alignment the full width; move levels/filter/crossfader below; disclose cues and full mixer on demand. | Less persistent EQ information. |
| Studio Grid | Studio | Preserve collection-left / four-deck-right, strengthen track hierarchy and make control sizing consistent. | Dense, but familiar to the selected Studio workflow. |
| Studio Linear | Studio | Four readable horizontal lanes with waveform and transport on one scan line; cue banks expand individually. | More horizontal space per track, cues on demand. |
| Studio Sync | Signal + Studio | Shared pair alignment above four deck controls, with persistent collection and working A/B–C/D selection. | Combines both accepted ideas at higher information density. |

All five are authored by Hermes. The same synthetic track collection and low-level controls are reused for fair comparison. No new production framework, audio engine or hardware integration is selected.

## Unchanged controls

The comparison also includes **Signal 02** and **Studio 02**, clearly separate from the five numbered new studies. Their original HTML bytes are preserved; their SHA-256 values live in `references.json`. The publication checker verifies both the source files and embedded reference payloads against those fingerprints. Previous rounds are not overwritten.

## Portable review

Open `deck-craft-refinements-03.html`. All seven documents are embedded for offline use. The five numbered tabs select new proposals; Originals buttons select the two reference controls. Focus hides review chrome, Phone layout exposes the responsive arrangement, 100% / pan allows full-size desktop inspection on a phone, and Download exports the current HTML. Switching studies resets local demo state.

## Interactive scope

Exposed transport, cue, loop, Sync, pads, search, crate filters, loading demo metadata/artwork, knobs, mixer dialogs, Prepare mode and density changes operate locally. New Grid/Detail buttons, cue disclosures and pair selectors change their visible state. Detail zoom is a synthetic plot zoom, not audio analysis. Loading a demo track does not calculate or replace its synthetic waveform fixture.

The UI contains no external resources, telemetry, personal music, credentials or private infrastructure details. All art, tracks and waveforms are original synthetic fixtures. No audio is produced. Visual preference remains for the user to judge; passing browser checks is not aesthetic acceptance.
