# Studio Linear

Author: Hermes. Round 03.

## Selected lineage
Studio from Round 02.

## Refinement
Four sources. Four clear lanes.

Keeps Studio’s persistent collection, but presents decks as horizontal lanes. Waveforms and transport read across; hot cues expand per deck.

## Trade-off
Improves scan order and long track titles; cue banks are collapsed until needed.

## Prototype scope
Offline synthetic fixtures. Transport, cue, loop, library filtering/loading and mixer controls simulate UI state only. Exposed cue disclosures, mixer dialogs, grid/detail and deck-pair controls operate locally. No audio or hardware connection.
