# Design Studies / Round 02

## The correction

The first round was rejected. Its repeated bordered panels, generic headings, ornamental waveforms and weak control hierarchy did not convey a professional DJ application. This is a new visual exploration, not a recoloring of those files.

The primary surface is **Operate**: loaded tracks, time, waveform alignment, cue/loop controls, mixer and collection. There are no marketing headlines inside the application. Compact application chrome, a deliberate technical type hierarchy, original geometric sleeves, textured platters and synthetic frequency-style envelopes replace the previous generic dashboard treatment.

## Five stances

- **Obsidian:** stacked phrase alignment across the top, two decks, central mixer, collection below. Most conventional professional mixing layout.
- **Signal:** horizontal waveform alignment dominates; deck metadata/transport sits above and the mixer moves to the right. Fewer physical metaphors.
- **Alloy:** warm light surfaces and mineral greens, compact wave decks and pale instrument controls. A deliberate light-workspace alternative.
- **Nocturne:** a vertical phrase tower between mirrored platters, violet/rose deck identity and a separate mix strip. A different operating composition, not just another dark palette.
- **Studio:** collection on the left, four decks on the right, effects above and mix controls below. Designed for collection access during layered performance.

Inspected Native Instruments' official Traktor Pro product page and interface gallery to understand professional waveform, mixer and collection density. The Serato overview documentation was discoverable but its page was blocked by a security check; it was not treated as a visually inspected reference. No reference screenshots, proprietary assets or source code are bundled. The layouts, artwork, waveforms and code in these studies are original synthetic designs.

## Limits

This round changes visual craft and composition, not the product's implementation status. All tracks/art/waveforms are synthetic. Mixer, FX and transport simulate UI state; there is no audio processing, controller input or device connection. Loading changes track metadata and cover artwork but does not analyze or replace the synthetic waveform fixture. No visual direction has been accepted yet.
