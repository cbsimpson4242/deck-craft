# Alloy

Author: Hermes. Round 02.

## Design stance
A calibrated studio instrument.

Warm mineral surfaces, olive controls and clean type. A daylight alternative to the usual black booth.

## Trade-off
Clear preparation and long-session legibility; intentionally not a nightclub palette.

## Scope
Offline visual prototype. Play/Pause, cue, sync, loop size, cue pads, knobs, search, crate filters, loading demo track metadata, Prepare mode and library density are interactive. No audio processing. Loading updates metadata; waveform and cover are synthetic layout fixtures, not an analyzed track.
