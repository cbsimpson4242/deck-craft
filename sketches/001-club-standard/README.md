# Club Standard

Author: Hermes

## Design stance
Dual decks keep track context, transport and the mixer in one predictable field of view.

## Key choices
- Layout: Club Standard workflow.
- Typography: system sans with monospaced technical readouts.
- Color: restrained neutral surfaces and functional deck accents.
- Interaction: demo play/pause, cue reset, pad toggles, search and Load A; pitch sliders update labels. No audio.

## Trade-offs
- Strong at: Familiarity and fast scanning.
- Weak at: Dense on narrow screens.

## Best for
Familiarity and fast scanning.
