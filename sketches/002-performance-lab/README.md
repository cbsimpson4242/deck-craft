# Performance Lab

Author: Hermes

## Design stance
Four sources. Eight cue points per deck. A performance-first surface for layered sets.

## Key choices
- Layout: Performance Lab workflow.
- Typography: system sans with monospaced technical readouts.
- Color: restrained neutral surfaces and functional deck accents.
- Interaction: demo play/pause, cue reset, pad toggles, search and Load A; pitch sliders update labels. No audio.

## Trade-offs
- Strong at: Layering and performance access.
- Weak at: More cognitive load; less library space.

## Best for
Layering and performance access.
