# Library First

Author: Hermes

## Design stance
Browse, prepare and shape your collection before stepping into the mix.

## Key choices
- Layout: Library First workflow.
- Typography: system sans with monospaced technical readouts.
- Color: restrained neutral surfaces and functional deck accents.
- Interaction: demo play/pause, cue reset, pad toggles, search and Load A; pitch sliders update labels. No audio.

## Trade-offs
- Strong at: Track preparation and search.
- Weak at: Only one audition deck; not a live mixing layout.

## Best for
Track preparation and search.
