# Hardware Console

Author: Hermes

## Design stance
A console-like layout with platter landmarks, channel strips and warm instrument lighting.

## Key choices
- Layout: Hardware Console workflow.
- Typography: system sans with monospaced technical readouts.
- Color: restrained neutral surfaces and functional deck accents.
- Interaction: demo play/pause, cue reset, pad toggles, search and Load A; pitch sliders update labels. No audio.

## Trade-offs
- Strong at: Tactile hierarchy and booth feel.
- Weak at: Platters consume waveform and library space.

## Best for
Tactile hierarchy and booth feel.
