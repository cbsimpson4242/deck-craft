# Deck Craft

![Deck Craft](assets/deck-craft.svg)

An open-source DJ software project built around professional workflows, reliable performance, and community ownership.

**Status: project foundation and UI exploration. There is no audio engine or playable DJ application yet.** Serato, Traktor and other professional tools are workflow benchmarks, not affiliations or claims of parity.

## Explore the designs

Download and open [the portable comparison](designs/deck-craft-comparison.html) in a browser. It contains five complete offline, interactive design prototypes. No server, dependencies, account, music files or network access are needed. Individual designs live in `sketches/`.

1. Club Standard — familiar dual-deck mixing.
2. Performance Lab — four decks and performance tools.
3. Library First — preparation and collection management.
4. Minimal Precision — focused, stripped-back mixing.
5. Hardware Console — equipment-inspired tactile controls.

All track names, artists, waveforms, times and library entries are synthetic demonstration fixtures. Play, cue, sync and pads only change prototype state; they do not produce or process audio.

## Product direction

Long-term: capable mixing, track preparation, library management, cue/loop workflows, effects, controller integration and dependable real-time audio. Platforms, stack, audio architecture and feature milestones are not selected yet. Professional parity must eventually be demonstrated by real audio, performance and hardware tests—not screenshots.
