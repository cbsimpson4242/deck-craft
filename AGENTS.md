# Deck Craft handoff

Read README.md, PROGRESS.md and SECURITY.md first. This is an independent open-source DJ project. Preserve original branding, synthetic fixtures and all historical design files. Never publish private machine/network/account/service details or local state.

## Approved direction and current authority

The user approved all five Round 03 layouts as interchangeable views: Signal One, Signal Wide, Studio Grid, Studio Linear and Studio Sync. The current implementation is an application UI foundation with shared state and device-local preference persistence. Studio Sync is the default. Do not return to selecting a single winner or substitute a prototype iframe/comparison page for the app.

No audio engine, real playback, waveform analysis, DSP, hardware integration, native packaging or network backend has been selected/authorized by this milestone. Keep visible no-audio notices and restore saved sessions paused. Do not call a UI transport state audible playback.

## Source authorities

- `src/session.js`: pure four-deck session transitions and bounded snapshot restoration.
- `src/store.js`: the only local persistence owner.
- `src/components.js`, `src/views.js`, `src/main.js`: shared controls, layout composition and real event handlers.
- `src/approved.css`: complete approved stylesheet; generated by `scripts/sync-approved-css.mjs`. Do not reconstruct it from truncated tool output or edit the historical design files.
- `src/app.css`: application-specific controls and responsive rules.

Renderers do not own independent deck models. A layout action must not alter musical state, unload hidden C/D, remount a separate application or reload the document. Keep state-model and browser transition tests mandatory for layout changes. Preserve unrelated work with isolated branches/worktrees and explicit integration.
